‌What is it?‌

DSCUSBDrvXX.DLL is a standard Windows DLL that can be used to help your own Windows PC applications communicate with the Mantracourt DSCUSB instruments using the ASCII protocol. These include DSCSUASC and DSCSUEASC.

The DLL will allow you to read and write instrument parameters and execute commands. Refer to the DSCUSB Advanced Manual to determine command names.

This DLL is a helper DLL that wraps up a lot of things to make communication with the DSCUSB much easier. This DLL must be used in conjunction with the FTDI driver which can be found on the Mantracourt web site.

NOTE: The DLL will halt all processing while waiting for a response from the instrument.

‌Who Can Use It?

The DLL is provided as freeware and is free to use however you wish. Anyone using a development tool that can use standard Windows DLLs can use this DLL.

‌What Can It Be Used With?

Visual Basic, Delphi, C++ Builder and many other development tools can use the DLL. We provide examples for VB6 and executables (Standalone) for testing both 32bit and 64bit. All operating systems from Windows 95 upwards are supported. Some functions require you to state the name of the commands you need to interact with. The DLL will automatically adapt to use either Unicode strings or ascii strings based on what you supply

‌How To Use It

You need to declare the DLL functions in your development tool before use so please refer to your development tool documentation or our examples.

NOTE: The DLLs are installed into the created application folder by the supplied installation package. When creating your own installation please bear in mind that the DLL should be installed to the system folder of the target computer or reside in the same folder as your created executable application. The system folder for DSCUSBDrv32.dll is

\Windows\SysWOW64 and for DSCUSBDrv64 the system folder is \Windows\System32.

The DLLs are accompanied by .lib and .exp Library and export files which may be of use in your chosen development language but these files are not needed by any generated executables.



Important: If used in Delphi or C Builder these functions need to be declared as StdCall.

This DLL has been re-written to allow for both 32 bit and 64 bit versions. If you have previously used DSCUSBDrv.dll here are the changes.

  • The DLL filename has changed to DSCUSBDrv32.dll for the 32 bit version and DSCUSBDrv64.dll for the 64 bit version.


  • All previous int return values and arguments are now longs.
